# Мир Колец — интерактивная карта

## Запуск
Проект использует Leaflet.js с CDN, поэтому для первого запуска нужен интернет.

Не открывайте `index.html` напрямую через `file://`: браузер может заблокировать загрузку JSON.
Запустите локальный сервер из папки проекта, например:

```bash
python -m http.server 8000
```

Затем откройте http://localhost:8000


## Где редактировать данные
- `data/config.json` — размер карты, толщину рамки (`map.frameWidth`, в пикселях), режимы и цвета интерфейса.
- `data/locations.json` — точки, их координаты, типы и пути к Markdown-описаниям.
- `data/types.json` — категории и значки для каждого типа объектов.
- `data/descriptions/<тип>/` — Markdown-описания точек, разложенные по типу.
- `assets/maps/<режим>/map.svg` — изображения подложек. Их можно заменить PNG/JPG/SVG, сохранив одинаковые размеры и пути (или обновив config.json).

## Большие карты
Большие растровые карты автоматически показываются тайлами: загружается только видимая часть карты и подходящий уровень масштаба. Чтобы нарезать новую карту, установите Pillow один раз и передайте исходное изображение генератору:

```bash
python -m pip install -r requirements.txt
python tools/tile_map.py assets/maps/geographical/map.png
```

Генератор создаёт WebP-пирамиду в `assets/maps/geographical/tiles/` и подключает её ко всем режимам, которые используют этот исходный файл. Если файл находится вне проекта, укажите режим, например `python tools/tile_map.py C:/Maps/new-map.png --mode geographical`; файл будет скопирован в папку режима. После завершения обновите страницу атласа.

## Настройка интерфейса
В `data/config.json` изменяйте цвета в объекте `theme.colors`. Значения задаются HEX-кодами с 6 или 8 цифрами, например `"accent": "#8b6840"`. Основные ключи: `ink`, `muted`, `paper`, `panel`, `line`, `accent`, `dark`, `map-bg`, `marker-bg`, `marker-active` и `tooltip-bg`.

Палитра `theme.colors` используется для светлой темы, а `theme.darkColors` — для тёмной. Переключатель находится в шапке; выбранная тема сохраняется в браузере.

Изображение логотипа задаётся в `branding.logo` в `data/config.json`. Можно заменить `assets/icons/brand.svg` своим изображением или указать другой путь.

Ширину бокового меню можно менять перетаскиванием разделителя между картой и меню, вплоть до половины экрана. Выбранная ширина сохраняется в браузере.

## Координаты
Начало координат данных находится в левом верхнем углу изображения:
- `x` растёт слева направо;
- `y` растёт сверху вниз.
Leaflet преобразует Y при размещении маркеров.

## Добавление точки
Добавьте объект в `data/locations.json`, задав уникальный `id`, `name`, `type`, `coordinates` и `descriptionFile`. Режимы показа задаются у типа в `data/types.json`, а не у каждой точки.

Быстро добавить точку можно кнопкой «Добавить точку» (✚) на панели карты: включите режим, щёлкните по месту, заполните название, тип и описание. Координаты, ID и путь к Markdown-файлу сформируются автоматически. Файл описания можно скачать отдельной кнопкой в карточке точки и сохранить в `data/descriptions/<тип>/<id>.md`. Все точки скачиваются кнопкой «Скачать все точки» в шапке; замените полученным `locations.json` файл `data/locations.json`. Кнопка «Скачать все Markdown» загружает ZIP-архив с описаниями в исходных папках по типам; распакуйте архив в корень проекта. Новые точки и удаления хранятся только в текущем сеансе браузера, поэтому скачайте общий список до перезагрузки страницы.

Удалить точку можно из её карточки. Удаление действует в текущем сеансе; скачайте общий `locations.json`, чтобы сохранить его. Markdown-файл удалённой точки останется в папке проекта — удалите его вручную, если он больше не нужен.

Из карточки также можно изменить название, тип, описание и координаты точки. Чтобы задать новые координаты, нажмите «Выбрать место на карте», щёлкните по нужному месту, затем сохраните изменения в форме. Изменения действуют в текущем сеансе: скачайте `locations.json`, а обновлённое описание — кнопкой Markdown в карточке или общим ZIP-архивом. При смене типа путь описания автоматически меняется на `data/descriptions/<новый-тип>/<id>.md`.

Кнопка ⚄ под кнопкой перехода к выбранной точке выбирает случайную точку среди тех, которые отображаются в текущем режиме и не скрыты настройками видимости значков, затем перемещает к ней карту.

В карточке точки можно изменить её название, тип и Markdown-описание. Если поменять тип, путь описания автоматически изменится на `data/descriptions/<новый-тип>/<id>.md`; скачайте общий Markdown-архив и распакуйте его в корень проекта, чтобы сохранить описание в новой папке. Обновлённые поля точки сохраняются в `locations.json`, скачайте его отдельно.

Точки с `demo-` в `id` добавлены для примера значков типов, у которых ранее не было координат. Их названия и положения условные.

Чтобы добавить тип, создайте запись в `data/types.json`: ключ записи будет значением `type` у точек. Укажите категорию, массив `modes` и значок. Режим `all` показывает иконки любых типов независимо от их `modes`. Для текстового символа можно настроить HEX-цвет символа и фона, а также размер: `"icon": { "symbol": "✦", "color": "#c49a46", "backgroundColor": "#f0e4c4", "scale": 1.5 }`. `scale` — множитель размера всего значка (символа и фонового круга), по умолчанию `1`; допустимые значения больше `0` и не выше `3`. Для изображения используйте `"icon": { "image": "assets/icons/my-icon.svg" }`; его цвет сохраняется из исходного файла, а `backgroundColor` задаёт фон контейнера значка. Если `backgroundColor` не указан, применяется цвет текущей темы. Фильтры и настройки видимости категорий строятся автоматически.

Markdown-файлы точек хранятся в `data/descriptions/<тип>/<id>.md`; путь задаётся в `descriptionFile`. Поддерживаются заголовки `#`–`####`, абзацы, маркированные списки, **полужирный**, *курсив* и `код`. Ссылка на другую точку задаётся расширением Markdown `[[id-точки|текст ссылки]]`; также поддерживается `[текст](poi:id-точки)`. При нажатии откроется карточка связанной точки без автоматического перемещения карты.

Значки можно скрыть все сразу или отключить отдельные категории в панели «Видимость значков». Фильтр категорий списка независим от видимости маркеров.



  "city": {
    "category": "Поселение",
    "icon": {
      "image": "assets/icons/valden.svg"
    }
